# Prototype controls

- Click the window to capture the mouse; Escape releases it. Click again to resume.
- Mouse: look. W/A/S/D: move. Space: jump. Double-tap Space: toggle flight.
- In flight, hold Space to rise and Shift to descend. Hold Control to move faster.
- Left click: break a targeted block. Right click: place the selected block.
- Number keys 1–9 or mouse wheel: select a hotbar block.
- Close the window normally to exit. Edits are also saved after each change when a user data directory is available.

These controls describe the prototype and have not yet been tested on Windows.
