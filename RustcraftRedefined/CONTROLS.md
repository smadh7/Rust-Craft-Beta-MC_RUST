# Prototype controls

At startup, choose graphics and a hand style. Select an existing world and click **Play selected world**, or enter a new name and numeric seed and click **Create world & play**. **Quick play** starts an unsaved world using the seed field. To return to the menu, close and restart the game.

- Click the window to capture the mouse; Escape releases it. Click again to resume.
- Mouse: look. W/A/S/D: move. Space: jump. Double-tap Space: toggle flight.
- In flight, hold Space to rise and Shift to descend. Hold Control to move faster.
- Left click: break a targeted block. Right click: place the selected block against the targeted face.
- Number keys 1–9 or mouse wheel: select a hotbar block.
- F1: Potato / Basic; F2: Normal; F3: High; F4: Very High / Peak. The active preset appears in the window title. Presets reset to Normal on restart.
- Close the window normally to exit. Edits are also saved after each change when a user data directory is available.

These changes have not yet been play-tested on Windows.
