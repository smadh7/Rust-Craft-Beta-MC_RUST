# Rustcraft Redefined

An unofficial, clean-room voxel sandbox written in **Rust** with a **C++** native core,
working towards feature parity with Minecraft: Java Edition 26.2. It is a playable survival and
creative game with crafting, mobs and saved worlds, but far from the whole of Minecraft; the
inner README lists exactly what works and what is missing.

- Play in a browser: open `RustcraftRedefined/web/index.html` (WebGL 2).
- Play on Windows: run `RustcraftRedefined.exe` (OpenGL 3.3).
- Everything else — status, building, controls — is in [`RustcraftRedefined/README.md`](RustcraftRedefined/README.md).

[`RustcraftRedefined/NOTICE.md`](RustcraftRedefined/NOTICE.md).
